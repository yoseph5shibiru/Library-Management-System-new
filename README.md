# 📚 Library Management System (C++)

A simple and efficient **Library Management System** developed using **C++** and Object-Oriented Programming principles.  
This console-based application helps manage books, members, and library operations such as issuing and returning books.

The project is ideal for beginners learning:
- C++ programming
- Object-Oriented Programming (OOP)
- Header and source file organization
- Modular programming
- Library management logic

---
# 🚀 Features

## 📖 Book Management
- Add new books
- Display available books
- Search books by title or ID
- Remove books from the library

## 👥 Member Management
- Add library members
- View member details
- Manage borrowing records

## 🔄 Library Operations
- Issue books
- Return books
- Track borrowed books
- Maintain library records

# ⚙️ How to Compile and Run

## 🔹 Compile the Project

Using g++:

```bash
g++ main.cpp book.cpp member.cpp library.cpp -o library
```

## 🔹 Run the Program

### Windows

```bash
library.exe
```

### Linux / Mac

```bash
./library
```
